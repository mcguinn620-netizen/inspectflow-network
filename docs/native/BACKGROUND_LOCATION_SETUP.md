# Background mileage tracking setup (Capacitor)

This app now includes `@transistorsoft/capacitor-background-geolocation` and uses it for active trip tracking on native iOS/Android.

## Installed plugin

- `@transistorsoft/capacitor-background-geolocation`

After pulling this branch locally:

```bash
npm install
npx cap sync
```

## iOS requirements

Already checked into this repo:

- `Info.plist` location usage strings:
  - `NSLocationWhenInUseUsageDescription`
  - `NSLocationAlwaysAndWhenInUseUsageDescription`
  - `NSLocationAlwaysUsageDescription`
- `UIBackgroundModes` includes `location`

### Manual Xcode steps

1. Open `ios/App/App.xcworkspace`.
2. Select the **App** target → **Signing & Capabilities**.
3. Add capability **Background Modes**.
4. Enable **Location updates**.
5. Build & run on a real device and grant **Always Allow** location permission.

## Android requirements

After `npx cap add android` (or in existing Android project), ensure `android/app/src/main/AndroidManifest.xml` includes:

```xml
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_LOCATION" />
```

Also ensure the background geolocation foreground service declaration generated by the plugin remains present after sync/merges.

### Manual Android Studio steps

1. Open Android project from `npx cap open android`.
2. Verify runtime permission flow requests foreground first, then background location.
3. Confirm persistent notification text/channel for active mileage tracking.
4. Test with screen locked and with Google Maps/Waze in foreground.

## Tracking behavior in app

- Native + permissions + plugin available: **Background tracking on**.
- Native without background permission/plugin: **Foreground tracking only** (with warning).
- Missing location permission: **Location permission needed**.
- Trip paused: **Tracking paused**.

Foreground fallback (Capacitor/browser geolocation) remains in place for web/PWA or unsupported native setups.
